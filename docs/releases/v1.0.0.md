# ISyMCP 1.0.0

The first stable release of the local ChatGPT / HTTP / MCP bridge. It keeps the
isolated Codex profiles, scoped native tools and source-only distribution of the
release candidates, and consolidates the security, stability and documentation
work completed since rc.2.

This is still experimental software for local use. It is not affiliated with,
endorsed by or approved by OpenAI, and a successful technical test is not
permission to automate the consumer web interface.

## What changed

### Security

- The bridge now creates its own token (`<home>/token`, mode 0600) on first
  start and requires it on every loopback route: `/v1/*`, `/isymcp/*`, health,
  metrics and the WebSocket. If the token cannot be prepared, requests fail
  closed with 503 instead of leaving the bridge open.
- A reported OpenAI block on the MCP `chatgpt_ask` route is recorded as
  `provider.blocked`, returns `provider_blocked` with `isError`, and is never
  retried.
- The native broker socket moved from the shared `/tmp` path to a private 0700
  directory: `$XDG_RUNTIME_DIR/isymcp/broker.sock` or
  `<bridge home>/run/broker.sock`. The tunnel launcher and connect script agree
  on the same path.
- `bun audit` reports 0 vulnerabilities in 116 packages, down from 14
  (6 high, 6 moderate, 2 low), after upgrading
  `@modelcontextprotocol/sdk` to 1.32.2 and refreshing body-parser 2.4.0,
  fast-uri 3.1.9, ip-address 10.7.4, qs 6.16.1 and zod 4.6.6.
- `SECURITY.md` documents private reporting, supported versions and scope.

### Stability and maintenance

- Process-spawning integration tests declare explicit 30-90 s budgets instead
  of relying on Bun's 5 s default; the global default stays at 5 s for unit
  tests.
- `src/` has no line longer than 160 columns; the formatting change was
  verified literal-by-literal and regex-by-regex against the previous commit.
- The Windows sandbox image tag is now `isymcp-sandbox:1.0.0`.

### Decisions

- The account owner accepted `docs/compliance/FINAL_VERDICT.md`: automated
  consumer-web operation and retries after safety blocks remain vetoed.
- The autonomous native-browser line is frozen for 1.0.0. Both modes report
  `blocked`, entrypoints return `503 native_browser_unavailable`, and no remote
  retries are performed. It will only be revisited with a documented,
  authorized owner/browser adapter and a new owner decision.

## Download & install

Download `isymcp-v1.0.0.tar.gz` or `.zip` and `SHA256SUMS` from Assets below.
These contain source code, not standalone executables.

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf isymcp-v1.0.0.tar.gz
cd isymcp-v1.0.0
bun install --frozen-lockfile
bun link
isymcp --version
```

Bun 1.4.2 is the CI runtime. Local sandboxed tools require Linux and bubblewrap;
media tools additionally require FFmpeg/ffprobe. Chrome and a configured session
are required for Web-provider features. Follow the README and GUIA.md for setup.

## Scope

This remains an experimental, unsupported ChatGPT Web integration. Browser
changes, authentication and platform blocks can interrupt operation. The
internal policy review is not approval by OpenAI. Keep scoped permissions and
review the limitations before connecting an account.

The rc.1 and rc.2 tags remain unchanged; 1.0.0 is a new snapshot published only
after its own CI succeeds.

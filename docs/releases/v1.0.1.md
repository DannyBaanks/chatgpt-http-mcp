# ISyMCP 1.0.1

Patch release on top of 1.0.0. It ships a single diagnostics fix; the bridge,
MCP tools, sandbox and network behaviour are unchanged.

This is still experimental software for local use. It is not affiliated with,
endorsed by or approved by OpenAI, and a successful technical test is not
permission to automate the consumer web interface.

## What changed

### Fixed

- `isymcp doctor` no longer pins a stale media failure to the report. The
  last-failure check now compares the most recent failed import against the most
  recent completed import: once the catalog has recovered, the check reads
  `ok · sin fallos registrados` instead of a permanent warning.
- The warning was effectively un-clearable before. A historical failure that
  predates the stable error codes fell back to `media_unknown`, and the documented
  remedy ("retry the operation") could not dismiss it, because a successful retry
  writes a new job and leaves the old failed `job.json` as the latest failure.

Raw evidence is preserved: no `job.json` under the media catalog is deleted or
rewritten. Only the doctor's interpretation changed.

### Maintenance

- Version bumped to `1.0.1`; Windows sandbox image tag to `isymcp-sandbox:1.0.1`.

## Verification

- Full suite: **706 pass, 3 skip, 0 fail** across 709 tests in 107 files.
- `bun run typecheck` exits 0.
- New regression test covers both states (recovered catalog → ok, still-failing → warn).
- `runDoctor()` against the real catalog reports `media-error: ok`.
- The three skips are opt-in or platform-gated (Windows native MCP E2E, installed

## Download & install

Download `isymcp-v1.0.1.tar.gz` or `.zip` and `SHA256SUMS` from Assets below.
These contain source code, not standalone executables.

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf isymcp-v1.0.1.tar.gz
cd isymcp-v1.0.1
bun install --frozen-lockfile
bun link
isymcp --version
```

Bun 1.4.2 is the CI runtime. Local sandboxed tools require Linux and bubblewrap;
media tools additionally require FFmpeg/ffprobe. Chrome and a configured session
are required for Web-provider features. Follow the README and GUIA.md for setup.

## Scope

This remains an experimental, unsupported ChatGPT Web integration. The compliance
verdict stands: automated consumer-web operation and retries after OpenAI safety
blocks are vetoed, and the autonomous native-browser line stays frozen with
`503 native_browser_unavailable`. The `v1.0.0` tag and earlier releases remain
unchanged; 1.0.1 is a new snapshot published only after its own CI succeeds.

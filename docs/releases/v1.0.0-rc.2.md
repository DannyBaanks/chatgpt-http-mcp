# ISyMCP 1.0.0-rc.2

A release candidate for the local ChatGPT / HTTP / MCP bridge, with isolated Codex profiles, scoped native tools and a clearer release distribution.

## What changed

- Includes the merged Codex CLI/App profile isolation and visible-browser integration changes that landed after the rc.1 tag.
- README now links directly to releases, tags, the Spanish guide and evidence.
- CLI help and `--version` use the same package version.
- Versioned source archives include SHA-256 checksums; publication waits for successful CI on the exact commit.

## Download & install

Download `isymcp-v1.0.0-rc.2.tar.gz` or `.zip` and `SHA256SUMS` from Assets below. These contain source code, not standalone executables.

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf isymcp-v1.0.0-rc.2.tar.gz
cd isymcp-v1.0.0-rc.2
bun install --frozen-lockfile
bun link
isymcp --version
```

Bun 1.4.2 is the CI runtime. Local sandboxed tools require Linux and bubblewrap; media tools additionally require FFmpeg/ffprobe. Chrome and a configured session are required for Web-provider features. Follow the README and GUIA.md for setup.

## Verification & scope

The repository records a 2026-10-14 two-way canary and a historical run of 545 passing tests / 1 skipped. These records are maintainer evidence, not independent certification or a guarantee for every client. This release is published only after its own GitHub CI succeeds; consult that run for current results.

This remains an experimental, unsupported ChatGPT Web integration. The internal policy review is not approval by OpenAI. Browser changes, authentication and platform blocks can interrupt operation. Keep scoped permissions and review the limitations before connecting an account.

The old rc.1 tags remain unchanged. rc.2 provides a new snapshot instead of silently moving an existing tag.

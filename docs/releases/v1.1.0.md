# ISyMCP 1.1.0 — Control Center & MCP Integration

**An easier-to-use local control center for AI agents, tools and verifiable workflows.**

This release brings together the ISyMCP Control Center, a typed CLI command deck, task-monitor views, and a dedicated read-only MCP surface for overview, glossary, tasks and protocol. Private ChatGPT UI/app resources are included as **experimental integration components**; their presence in source does not establish successful installation or sidebar rendering on every ChatGPT host.

## Highlights

- **Control Center:** local dashboard and command deck with protected privileged actions.
- **Authority boundaries:** operator grants with HMAC checks, single-use consumption, expiry and workspace binding; independent ChatGPT app read-only surface.
- **Agent coordination:** task monitor, console registry and visibility into execution receipts.
- **Windows reliability:** improved session-registry lock contention diagnostics and stress coverage.
- **Documentation:** shorter product README and detailed technical reference.

## Security and compatibility

ISyMCP is independent and experimental; it is **not affiliated with or endorsed by OpenAI**. Some optional modes automate ChatGPT's consumer website and are neither the official OpenAI API nor guaranteed to be authorized by the platform. Use supported official programmatic interfaces when needed. The local permission and sandbox model does not replace upstream permission checks. Never publish session credentials or operator grants.

## Verification and limits

The automated release workflow publishes source archives **only after a successful push-triggered CI on the exact commit on `main`**. The GitHub Actions CI link appended to these release notes identifies that verification. Local test reports and experimental E2E evidence are separately documented; they do not constitute independent third-party certification.

## Download and install

Download `isymcp-v1.1.0.tar.gz` or `isymcp-v1.1.0.zip` plus `SHA256SUMS`. The archives contain **source code**, not precompiled executables.

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf isymcp-v1.1.0.tar.gz
cd isymcp-v1.1.0
bun install --frozen-lockfile
bun link
isymcp --version
```

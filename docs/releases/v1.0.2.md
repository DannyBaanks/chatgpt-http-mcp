# ISyMCP 1.0.2

Security and boundary hardening release following an architectural review
using the Elephant-Goldfish Model (EGM) and peer adversarial review.

This release addresses loopback administrative privilege boundaries, process tree
lifecycle guarantees, workspace confinement escapes, and introduces 11 automated
adversarial regression tests.

This is experimental software for local use. It is not affiliated with,
endorsed by or approved by OpenAI.

---

## What changed

### Security & Trust Boundary Hardening

- **Panel Credential Isolation & Loopback Hardening (`src/panel.ts`, `src/local-guard.ts`)**:
  - Eliminated `window.__ISYMCP_TOKEN__` completely from DOM HTML, templates, and frontend scripts. Unauthenticated callers can no longer extract host credentials via `GET /`.
  - Introduced a single-use bootstrap ticket mechanism (`mintPanelTicket` / `redeemPanelTicket`). Running `isymcp panel` from the terminal mints an ephemeral UUID ticket and opens `http://127.0.0.1:8798/?ticket=<uuid>`.
  - The ticket is immediately redeemed and burned on arrival, issuing an HMAC-SHA256 signed session cookie (`isymcp_session=...; HttpOnly; SameSite=Strict; Path=/`). Direct visits to `GET /` without a ticket or cookie serve a clean login card (`renderLoginCard()`) with HTTP 200 containing zero secrets.
  - Mutating panel endpoints (`/api/action`, `/api/harness/apply`, `/api/chats/*`, `/api/settings/*`) mandate valid authorization via token header or session cookie; unauthenticated requests fail closed with HTTP 401.
  - Implemented loopback-only host validation at the gateway to prevent DNS rebinding or external Host header spoofing across all panel endpoints.

- **Recursive Process Tree Cleanup on Linux (`src/platform/process.ts`, `src/mcp/exec-registry.ts`)**:
  - `stopProcessTree` and `killUnregisteredProc` now execute `pkill -TERM -P <pid>` while the parent process is alive, followed by process-group kill (`process.kill(-pid, "SIGTERM")`) and hard timeout escalations (`pkill -9 -P <pid>`). Detached background descendant jobs (`bash -c 'sleep 120 &'`) are terminated completely without leaving zombie processes.

- **Symlink Confinement Hardening (`src/codex-sessions.ts`, `src/mcp/main.ts`)**:
  - `runApplyPatch` now validates target paths using `resolveWithinReal`, recursively resolving parent directories to prevent symlink traversal escapes outside the authorized workspace root before applying file modifications.

- **Synchronous Session Validation & Multi-Turn Background Tasks (`src/mcp/exec-registry.ts`, `src/mcp/main.ts`)**:
  - Background execution records (`LiveExec`) are indexed by the root session fingerprint (`session.parent ?? session.fp`), allowing subsequent turns in a multi-turn conversation to manage background processes across turn boundaries.
  - `findLive` and `sweepLiveExecs` validate active sessions synchronously against `codex-sessions.json` on disk, terminating active processes immediately upon session revocation or expiration.

### Maintenance & Tests

- Version bumped to `1.0.2`; Windows sandbox image tag to `isymcp-sandbox:1.0.2`.
- Added automated adversarial security test suite in `tests/security-boundary.test.ts` covering 11 explicit verification invariants (`SEC-TEST-01` through `SEC-TEST-11`).

## Download & install

Download `isymcp-v1.0.2.tar.gz` or `.zip` and `SHA256SUMS` from Assets below.
These contain source code, not standalone executables.

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf isymcp-v1.0.2.tar.gz
cd isymcp-v1.0.2
bun install
bun test
```
